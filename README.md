# Talabalar ro'yxati: ma'lumotlar tuzilmasini tanlash

"Dasturiy tizimlarni loyihalash" fanidan 3-laboratoriya ishi (TDTU).

Talabalar ro'yxatini saqlash uchun **hash-jadval (Python `dict`)** tanlangan,
kalit — talaba ID si. Qidirish, qo'shish va o'chirish o'rtacha O(1) vaqtda
bajariladi. `main.py` oxirida `list` va `dict` qidiruv tezligi taqqoslanadi.

## Ishga tushirish

```bash
python main.py
```
